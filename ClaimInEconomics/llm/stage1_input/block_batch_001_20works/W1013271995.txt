Definition 1. Consider two finite sets of types $\mathcal { C } = \{ c _ { 1 } , \ldots , c _ { I } \}$ and $\mathcal { S } = \{ s _ { 1 } , \ldots , s _ { J } \}$ and a bipartite compatibility graph $G = ( { \mathcal { C } } , { \mathcal { S } } , { \mathcal { E } } ) ,$ with ${ \mathcal { E } } \subset { \mathcal { C } } \times { \mathcal { S } } ,$ assumed to be connected. Consider two independent random sequences $( c ^ { m } ) _ { m \in T }$ and ${ \left( s ^ { n } \right) } _ { n \in T }$ that are chosen, respectively, i.i.. from $\mathcal { C }$ with probabilities $\alpha = \{ \alpha _ { c _ { 1 } } , \ldots , \alpha _ { c _ { I } } \} ,$ and i.i.d. from $\mathcal { S }$ with probabilities $\beta = \{ \beta _ { s _ { 1 } } , \ldots , \beta _ { s _ { J } } \}$ The parameter set $T$ can be finite, for instance $T = \mathbb { I } _ { N } = 0 , 1 , 2 , \dots , N ,$ one sided infinite, $T = \mathbb { N } = 0 , 1 , 2 , 3 , . . . ,$ or two sided infinite, $T = \mathbb { Z } = \dots , - 2 , - 1 , 0 , 1 , 2 , 3 \dots .$ We assume that $\alpha _ { i } \neq 0$ for all $i$ and $\beta _ { j } \neq 0$ for all $j$ The triple $( G , \alpha , \beta )$ defines an infinite bipartite matching model. 
In the compatibility graph, $( c _ { i } , s _ { j } ) \in \mathcal { E }$ denotes that the types $c _ { i }$ and $s _ { j }$ are compatible and can be matched together. If $( c _ { i } , s _ { j } ) \notin \mathcal { E } ,$ we say that $c _ { i }$ and $s _ { j }$ are incompatible and they cannot be matched to each other. We study FCFS matchings between the two sequences, as defined precisely in Adan and Weiss [4], the exact definition is repeated in Section 2. Loosely speaking it means that an item from $S$ is matched to the earliest possible compatible item from C, and vice versa. This is unambiguously defined when $T$ is finite or when $T = \mathbb { N }$ In the case $T = \mathbb { Z } ,$ defining precisely the meaning of the FCFS matching is the purpose of Section 3. 
Figure 1illustrates FCFS matching of two sequences, for a given compatibility graph. Items are browsed from left to right. For instance, $c ^ { 1 }$ cannot be matched with $s ^ { 1 }$ nor $s ^ { 2 }$ since $c ^ { 1 } = c _ { 1 } , s ^ { 1 } = s ^ { 2 } = s _ { 2 }$ and $\left( c _ { 1 } , s _ { 2 } \right) \notin \mathcal { E } ,$ but it will be matched with $s ^ { 3 } = s _ { 3 } ,$ which is the earliest possible match.
