# 因果知识图谱领域分析

状态：已实施。

`/knowledge/causal-graph/fields` 是只读的领域与主题审计页面。它不使用热力图、Top 10
矩阵或 URL 中的选中子领域状态；这些方案已废弃，不应恢复。

## 当前页面

页面从两个只读 API 读取数据：

- `GET /api/knowledge/causal-graph/summary` 提供全库抽取记录、标准关系、论文和变量数。
- `GET /api/knowledge/causal-graph/fields` 提供领域/主题明细，以及全库高频关系、变量和方法分布。

首屏展示全库统计、高频关系（最多 8 项）、高频变量（最多 10 项）和方法分布
（前 10 项及合并的“其他”）。关系和变量均可下钻到既有详情页。下方“领域明细”表支持
子领域和主题文本筛选、排序与分页；未标注标签保留在该表中供审计。

## 统计口径

- 领域明细的声明记录数、论文数和变量数由后端的聚合查询提供。
- 高频关系显示抽取记录数、论文数和方法数，均为全库范围。
- 空方法名在方法分布中归为“未标注方法”；第 10 名之后的方法合并为“其他”。
- 领域或主题是论文标签，不应将多个领域/主题行简单相加后与全库总数比较。

## 缓存与刷新

领域分析结果在 Java 进程内缓存。外部 causal ETL 完成后，重启 Java 服务，再访问页面
以重建该缓存。缓存策略与已知的默认图谱缓存问题见
[`causal-graph-cache-plan.md`](causal-graph-cache-plan.md)。
