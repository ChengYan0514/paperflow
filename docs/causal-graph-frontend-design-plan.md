# 因果知识图谱前端设计调整方案

状态：待实施

## 背景与目标

本方案覆盖管理员端 `/knowledge/causal-graph` 下的总览、变量详情、关系详情、论文因果声明和领域分析页面。

目标用户是需要从大量论文因果声明中定位可靠关系、验证证据来源并比较研究分布的研究管理员。页面不应只是展示聚合数据，而应支持一条清晰的工作路径：**确定探索范围 -> 阅读网络结构 -> 下钻关系或变量 -> 核查论文证据**。

现有 Ant Design Pro 的浅色管理台框架、Alibaba Sans、紧凑卡片和表格继续保留。本轮不引入新的图表依赖；仅使用现有 `react-force-graph-2d`、Ant Design 组件和 CSS 实现。

## 设计原则

1. 图谱是探索界面的视觉中心，筛选和数据表为其服务，不能争夺首屏注意力。
2. 全局规模、当前结果和证据质量属于不同层级，不能以同样的统计卡并列呈现。
3. 每个详情页首先回答“这是什么、证据是否可靠、分布在哪里”，再呈现完整记录。
4. 色彩只表达因果方向和状态；数量使用位置、长度、数值和字重表达，不能只依赖颜色。
5. 桌面端用于比较和下钻，移动端优先阅读摘要与操作，宽表应横向滚动而非压缩术语。

## 视觉令牌与一致性

保持全局主色 `#1677ff`，将图谱和研究数据使用以下固定语义：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 正向因果 | `#2F8F5B` | 图谱边、方向标签和摘要中的正向计数 |
| 负向因果 | `#CF4C3F` | 图谱边、方向标签和摘要中的负向计数 |
| 无显著影响 | `#8C8C8C` | 图谱边、方向标签和摘要中的无显著计数 |
| 混合或不确定 | `#C9852B` | 图谱边、方向标签和摘要中的混合计数 |
| 研究结构蓝 | `#245B9E` | 未选中图节点；不与方向语义混用 |
| 次要文字 | `#667085` | 元数据、口径说明和辅助指标 |

延续当前 6-8px 圆角、白色实体卡片和轻边框。取消图谱图例的过强毛玻璃、阴影和 13px 圆角，使其成为低干扰的工具层。数字使用表格数字特性，变量名和关系名允许换行但不得逐字符断词。

## 页面调整

### 1. 总览 `/knowledge/causal-graph`

页面由“总览摘要、探索控制、图谱、结果核查”四层构成：

```text
[全库声明 | 标准关系 | 论文 | 变量] [数据版本/刷新时间]
[关键词、领域、最小记录] [高级筛选 v] [查询]
[                    因果网络画布                    ]
[图例/缩放提示]                         [当前结果摘要]
[高频关系表                                            ]
```

具体调整：

- 首行只保留四项全局指标：抽取记录、标准关系、论文数、变量数；当前节点和当前边移入图谱右上角的“当前结果”摘要。
- 将“最小记录数、最小方法数、最大节点数、最大边数”折叠到默认关闭的“高级筛选”。默认打开区域仅保留关键词、领域和最小记录数。
- 为“最小记录数”修正说明文字，明确它表示聚合记录数，避免误称为“被多少篇论文重复验证”。若要按论文阈值过滤，需新增独立的“最小论文数”。
- 查询按钮固定在筛选区右侧或移动端底部；重置只清除当前筛选，保留合理的图谱规模默认值。
- 图谱顶部不再重复使用卡片标题；在画布外给出简短、稳定的阅读提示：节点可打开变量，连线可打开关系。
- 高频关系表的默认排序与图谱当前筛选保持一致，并在标题中标注当前展示数量；在窄屏启用 `scroll.x`。

图谱渲染规则：

- 默认不绘制所有节点文字标签；只显示选中节点、hover 节点和高缩放级别下的标签。
- 节点 hover 显示变量名、主领域、出现次数；点击后进入变量详情。
- 仅在有选中节点或关系时显示高亮描边；其余节点保持低对比度，避免压过因果边颜色。
- 图例改为 4 个紧凑色条与两条编码说明。桌面端固定左下，移动端默认收起。
- 加载过程使用骨架或画布内加载态，网络为空时明确说明是筛选条件导致还是暂无数据。

### 2. 变量详情 `/knowledge/causal-graph/nodes/:variable`

变量详情需要成为“变量研究画像”，而非两个边表的前置页面。

```text
[变量名] [主领域] [总记录 | 作为原因 | 作为结果]
[一跳关系图                              ]
[领域分布              ][年份分布         ]
[出边关系表             ][入边关系表       ]
```

- 页面标题直接显示变量名，`变量详情` 降为面包屑或辅助标签；主领域与总记录作为标题侧摘要。
- 保留三项数值卡，移除固定 `height: 120`；主领域改为可换行的文本信息卡，防止中英文领域名在统计数字样式中显得突兀。
- 使用现有 `subfieldCounts` 和 `yearCounts` 增加领域分布、年份分布。优先用排序列表和横向占比条，不新增图表库；空数据明确标注“未标注”。
- 一跳图谱仅展示与当前变量相关的前若干高证据关系，并在图谱旁或下方说明截断规则。
- 入边、出边表增加 `scroll={{ x: ... }}`。移动端依次显示摘要、图谱、出边、入边，分布模块置于图谱后。

### 3. 关系详情 `/knowledge/causal-graph/edges?cause=&effect=`

关系详情的首屏应让用户立即读出“方向、证据强度和一致性”。

```text
[原因变量  ->  结果变量] [记录 | 论文 | 方法 | 跨领域 | 时间跨度]
[正向 n | 负向 n | 无显著 n | 混合 n]  [一致性说明]
[证据记录（筛选、排序、展开原文）                         ]
```

- 将当前标题卡、三张统计卡和灰色方向文字合并为一个关系摘要带。四种方向使用语义色的计数 Chip，同时保留中文文字和数值。
- 补充后端已返回的跨领域数、主题跨度、时间跨度和方法列表；若字段为空，不显示无意义占位。
- 在摘要带中显示关系的方向分歧程度，并说明虚线在图谱中的含义，避免用户将“混合”误读为确定结论。
- 证据表保留为主内容。加入方向、领域、方法的前端筛选和默认“记录数/年份”排序时，需要同步 URL 查询参数，保证可分享与回退。
- 对缺少 `cause` 或 `effect` 的直接访问，展示带“返回图谱总览”操作的空状态，而不是请求空关系。

### 4. 论文因果声明 `/knowledge/causal-graph/papers/:workId`

- 论文标题为页面主标题，work ID 作为副标题；年份、来源、领域组织成一行引文元数据，不使用同权重的默认 Tag 堆叠。
- 将“返回论文详情”和“查看全文 Blocks”移动到标题操作区，使用图标加文字的普通命令按钮。
- 将“核心发现”视觉上置于声明记录、节点、关系之前，使该论文的研究贡献成为首个可读结论。
- 小型论文图谱仅用于解释论文内部结构，默认高度保持 360-420px；节点少时可展示标签，节点多时沿用总览的按缩放显示规则。
- 声明表新增“核心发现”列或可见标识；展开行把证据原文、原始主张和研究方法按小标题分组，减少长段落堆叠。

### 5. 领域分析 `/knowledge/causal-graph/fields`

领域分析不使用热力图、矩阵或“选中领域”状态。它的职责不是让用户在交叉表中找颜色差异，而是让用户快速比较各研究领域的覆盖规模、研究关系和证据方法，并在需要时进入完整审计记录。

页面采用“领域目录 + 研究画像 + 完整明细”的连续布局。领域是可扫描的研究对象，主题是其审计维度，因此不应把二者硬性拼成一个需要解释统计口径的二维图表。

```text
[领域目录：领域 | 论文 | 声明 | 关系 | 变量 | 主要方法]
[领域研究画像（按声明记录数排序的领域卡片）             ]
[领域关系与变量] [方法分布] [覆盖范围摘要]
[完整明细：子领域筛选 | 主题筛选 | 数据表]
```

- 首屏放置一张紧凑的“领域目录”表，而非统计卡墙。每行汇总一个领域的论文数、声明记录数、标准关系数、变量数和最高频方法；默认按声明记录数降序，允许按任意数值列排序。
- 目录表只负责比较，不承担领域详情展示。点击领域名称时，将下方完整明细表按该领域过滤并滚动到审计区；不写入 URL、不维护选中领域，也不需要回退逻辑。提供“清除领域筛选”恢复完整明细。
- 目录后的“领域研究画像”按领域逐项展开。桌面端每个领域是一张低边界的全宽信息带：左侧为领域名称和四项核心指标，中间为 3 条高频因果关系，右侧为前 3 个方法的占比条；移动端按同一顺序垂直排列。
- 画像默认展示研究覆盖最高的 6 个领域；其余领域通过“显示更多领域”展开。该控件只控制页面密度，不改变数据筛选或 URL。
- 每条高频关系保留领域内记录数、论文数和方法数，链接到关系详情；变量列表以紧凑的名称加次数形式出现，链接到变量详情。关系和变量都允许两行文本，数字右对齐。
- 方法分布采用无色彩竞争的灰蓝占比条，方法名称与百分比始终同时显示。空方法归为“未标注方法”；当长尾被合并时明确标为“其他方法”。
- “覆盖范围摘要”只用文字和数值说明：该领域包含多少主题、近期/最早数据年份（后端数据具备时）及未标注记录数量。避免从多标签聚合推导全库占比或跨领域合计。
- 完整明细保留审计定位。筛选输入采用固定宽度、表格使用横向滚动；当筛选结果为空时说明筛选范围而非展示空白区域。子领域筛选由目录点击或文本输入设置，主题筛选保持独立。

## 响应式与可访问性

- `>= 992px`：保持两栏详情和完整表格比较布局。
- `768px-991px`：统计卡每行两项，详情面板按内容优先级换行，图谱保留不低于 420px 的高度。
- `< 768px`：筛选区单列；高级筛选默认关闭；图谱高度 360px；图例默认收起；所有多列数据表必须横向滚动。
- 图谱元素、领域目录行、关系链接和方向 Chip 必须有可读名称、键盘焦点与 tooltip/弹层补充信息。方向色彩之外始终提供文字标签。
- 尊重 `prefers-reduced-motion`：减少力导向图的自动布局扰动，禁用非必要过渡。

## 实施顺序

1. 抽取因果图谱共用视觉样式与响应式表格配置，统一方向色、图例、标签可见性和空状态。
2. 重构总览筛选层级与图谱画布，完成大图可读性验证。
3. 完成领域目录、可比较的领域研究画像与明细联动筛选，保留现有明细审计功能。
4. 增强变量、关系和论文详情的研究画像与证据摘要。
5. 补齐移动端、键盘操作、加载/空状态，并在真实数据密度下截图验收。

## 验收标准

- 总览在 1440px 宽度下可在首屏辨认全局规模、核心筛选和图谱；高级阈值不默认占据主要高度。
- 在最大节点/边配置下，图谱仍能辨认节点团簇与连线方向，标签不会系统性覆盖画布。
- 领域分析可在不使用热力图或 URL 选中状态的情况下比较各领域；目录点击能可靠过滤完整明细，研究画像可直接下钻关系与变量。
- 变量详情可读出其领域与年份分布；关系详情可读出方向构成与证据覆盖；论文详情可识别核心发现和上下游跳转。
- 375px、768px、1440px 三种视口下不出现文字重叠、不可读断词或被压扁的多列表格。
- 图谱、领域目录、筛选、下钻链接和展开证据均具备键盘可达性；颜色不是理解方向或数量的唯一线索。
