Dually-Weighted Cross Decomposition for the Capacitated Facility Location Problem
Paul Wentges Institut für Unternehmensforschung der Hochschule St. Gallen Bodanstr. 6, 9000 St. Gallen, Switzerland 
Abstract
The cross decomposition algorithm of [van Roy 1986] is generally considered to be one of the most efficient procedures for solving the capacitated facility location problem. A modified version of this algorithm, called dually-weighted cross decomposition, is presented. In contrast to the cross decomposition algorithm, this approach does not use the optimal dual solutions of the primal subproblems or the optimal solutions of the dual master problem as Lagrangean multipliers for the dual subproblems. A specially weighted average of the previously constructed multipliers is used instead. Finite convergence of this approach is proven and first promising results are discussed. 
1 Introduction
The capacitated facility location problem (CFLP) can be formulated as the following mixedinteger programming problem (see e.g. [Cornuejols et al. 1991] for a more detailed description of the problem) : 
$$
 C F L P \middle > \{ \begin{array} { l l } { \displaystyle \operatorname* { m i n } \sum _ { j = 1 } ^ { n } f _ { j } y _ { j } + \sum _ { i = 1 } ^ { m } \sum _ { j = 1 } ^ { n } c _ { i j } x _ { i j } , } \\ { \displaystyle \sum _ { j = 1 } ^ { n } x _ { i j } = d _ { i } \forall i , } \\ { \displaystyle x _ { i j } \leq d _ { i } y _ { j } \ \forall i , j , } \\ { \displaystyle \sum _ { i = 1 } ^ { m } x _ { i j } \leq s _ { j } y _ { j } \ \forall j , } \\ { \displaystyle \operatorname* { m i n } _ { x _ { i j } \geq 0 , \ y _ { j } \in \ \{ 0 , 1 \} \ \forall i , j , } } \end{array} 
$$
where $_ m$ represents the number of customers, $n$ the number of potential facility locations, $d _ { i }$ the demand of customer $_ i$ , and $s _ { j }$ the capacity of facility $j$ . $c _ { i j }$ are the costs to transport one unit from facility $j$ to customer $_ i$ and $f _ { j }$ the fixed costs to maintain/build facility $j$ . The variable $y _ { j }$ indicates whether facility $j$ is opened $( y _ { j } = 1 )$ or not, and $\boldsymbol { x } _ { i j }$ represents the amount shipped from facility $j$ to customer $_ i$ . 
The cross decomposition algorithm of [van Roy 1986] simultaneously exploits both the primal structure (temporarily fixing the variables $_ y$ yields a normal transportation problem) and the dual structure (with relaxing the capacity constraints (3) in lagrangean fashion) of the (CFLP), i. e. combines Benders' decomposition and Dantzig-Wolfe decomposition in one single framework. The approach is motivated by the fact, that the primal subproblem can be viewed as a relaxed dual (Dantzig-Wolfe) master problem and the dual subproblem as a relaxed primal (Benders) master problem (see e.g. [van Roy 1983]). 
The main steps of the algorithm can be described as follows (let $( S D _ { \mu } )$ be the Lagrangean relaxation of $( C F L P )$ with respect to the capacity constraints (3) and the Lagrangean multipliers $\mu$ b $( M D _ { k } )$ the relaxed Dantzig-Wolfe master problem: $\textstyle \operatorname* { m a x } \{ \delta : \sum _ { j = 1 } ^ { n } f _ { j } y _ { j } ^ { t } +$ $\begin{array} { r } { \sum _ { i = 1 } ^ { m } \sum _ { j = 1 } ^ { n } c _ { i j } x _ { i j } ^ { t } - \sum _ { j = 1 } ^ { n } ( s _ { j } y _ { j } ^ { t } - \sum _ { i = 1 } ^ { m } x _ { i j } ^ { t } ) \mu _ { j } \geq \delta \forall t \in T _ { k } ; } \end{array}$ $\mu \geq 0 , \delta \in \mathbb { R } \}$ $( S P _ { y } )$ the transportation problem obtained when $_ y$ is fixed, and $( M P _ { k } )$ a relaxed Benders master problem; for a more detailed and explicit description of the problems see [van Roy 1986]): 
Step 1: Initialize and get a dual solution $\mu ^ { 1 }$ (by solving the primal subproblem $( S P _ { y ^ { 0 } } )$ with $y ^ { 0 } \equiv 1$ ).   
Step 2: Solve the dual subproblem $( S D _ { \mu ^ { k } } )$ : Let $( x ^ { k } , y ^ { k } )$ be an optimal solution. Perform a convergence test; if the test is not fulfilled, go to step 5.   
Step 3: Solve the primal subproblem $( S P _ { y ^ { k } } )$ : Let $( \lambda ^ { k + 1 } , \nu ^ { k + 1 } , \mu ^ { k + 1 } )$ be an optimal dual solution. Perform a convergence test; if the test is not fulfilled, go to step 5 (or step 4, see below), otherwise go to step 2 and set $k : = k + 1$ .   
Step 4: Solve the primal master problem $\left( M P _ { k } \right)$ : Let $y ^ { k + 1 }$ be an optimal solution. Go to step 3 and set $k : = k + 1$ .   
Step 5: Solve the dual master problem $( M D _ { k } )$ : Let $\mu ^ { k + 1 }$ be an optimal solution. Go to step 2 and set $k : = k + 1$ . 
In steps 2 and 3, cuts corresponding to the optimal solutions have to be added to the respective master problems; in each step, optimality has to be checked. If the Lagrangean dual is solved within a specified tolerance level $\tau$ (e.g. $0 . 5 \%$ ), one switches to Benders' decomposition (only usage of steps 3 and 4). 
The cross decomposition algorithm solves the (CFLP) in a finite number of steps, since the convergence tests prevent the algorithm from cycling and therefore, after finitely many steps, the method amounts to Benders' decomposition, which is known to be finite (see e.g. [van Roy 1983] and [Holmberg 1990], respectively).
